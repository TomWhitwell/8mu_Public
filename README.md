### 8mu Public Repo

This is the public repo for the Music Thing Modular 8mu midi controller. 

[Documentation is here](https://www.musicthing.co.uk/8mu)


Currently this contains firmware for 8mu v1, devices bought before August 2026 that have a SAMD21 chip. 

Devices bought after August 2026 are v2. They have v2 clearly marked next to the USB socket, and have a RP2040 chip. 
 
The current production SAMD21 8mu v1 firmware source is in
[`Firmware_v1/8mu`](Firmware_v1/8mu). Release firmware can be downloaded from the
[Smith-Kakehashi releases page](https://github.com/TomWhitwell/Smith-Kakehashi/releases).

This repo also contains source for the [legacy 8mu editor](https://tomwhitwell.github.io/Smith-Kakehashi/), which has now been replaced by the [main 16n Editor for 16m | 16nx | 8mu](https://16n-faderbank.github.io/editor/).
